5.3 · Inventario de flujos alternativos y de borde

Todo lo que puede salir mal, ya está diseñado.

F1 · Onboarding

Happy: passphrase → custodia → biometría → moneda → dashboard. Alterno: mismatch, cancelación del aviso, sin biometría (botón disabled).

F2 · Desbloqueo

Happy: inactividad → VaultGate → biometría → ruta previa. Alterno: 5 fallos → backoff 30 s, fallback passphrase.

F3 · Registrar gasto

Happy: FAB → sheet → Zod → tx:created. Alterno: importe 0, transferencia sin destino, CTA deshabilitado, deshacer 4 s.

F4 · Presupuesto

Happy: meta → 80% → toast warn. Alterno: 100% danger (sin rojo de castigo), upsert duplicado, cancelar meta.

F5 · Export ⇄ Import

Happy: cifrar → compartir → importar → LWW resumen. Alterno: hash mismatch, decrypt failed, formato no soportado, reemplazar cancelado.

F6 · Borrado total

Happy: BORRAR → export sugerido → modal doble → wipe → onboarding. Alterno: cancelación restaura Ajustes intacto.
